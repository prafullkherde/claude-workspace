## Prompts (`prompts/md/`)

Reusable system prompts and instructional blueprints for Claude.

| File | Purpose |
|------|---------|
| `Universal_Memory_Super_Prompt_v5.md` | Base operating blueprint for educational, concept-teaching, and architecture-style content. Uses neuroscience-based teaching principles — associative memory, metaphor, story encoding. |
| `freelancing_master_prompt_v4.md` | Freelance market strategist prompt covering India vs global pricing, net take-home calculations, taxation, and zero-to-first-client entry strategies. |
| `javascript_prompt_v1.md` | JavaScript architecture and evolution handbook prompt — covers ECMAScript history, V8/SpiderMonkey internals, and the full JS runtime era from birth to modern. |
| `React and Its Ecosystem.md` | Deep-dive React guide prompt targeting working developers who want internals, architectural confidence, and historical context — not a tutorial. |
